🔐 HOW TO ADD YOUR OWN CREDENTIALS & IPs TO LOGINS.TXT
═════════════════════════════════════════════════════════════

FILE FORMAT:
────────────────────────────────────────────────────────────
YYYY-MM-DD HH:MM:SS,IP_ADDRESS,USERNAME,PASSWORD

Example:
2026-05-11 10:20:00,104.22.0.1,ravi,ravi@123


📋 UNDERSTANDING THE DATA
────────────────────────────────────────────────────────────

✅ LEGITIMATE LOGINS (successful attempts):
   - Use password: 1234 (this is the ONLY correct password in the system)
   - Example: 2026-05-11 08:15:00,192.168.1.100,admin,1234
   - Result: ✅ SUCCESS (counted as valid attempt)

❌ FAILED LOGINS (brute-force attempts):
   - Use ANY password EXCEPT 1234
   - Example: 2026-05-11 08:00:01,192.168.1.10,admin,wrong
   - Result: ❌ FAILURE (counted as suspicious)

⚠️  HIGH RISK PATTERN (Brute-force detection):
   - Same IP, multiple wrong passwords in short time
   - Example: 5+ failed attempts from one IP = BLOCKED

STEP-BY-STEP: ADD YOUR DATA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. FIND YOUR IP ADDRESS
   ─────────────────────
   On Windows:
   - Open Command Prompt
   - Type: ipconfig
   - Look for "IPv4 Address" (e.g., 192.168.1.xxx)

   Or online: https://www.whatismyipaddress.com

2. EDIT logins.txt FILE
   ──────────────────────
   Option A: Open in VS Code
   - Right-click logins.txt → Open with Code
   - Scroll to the bottom
   - Add your entries
   - Save (Ctrl+S)

   Option B: Open in Notepad
   - Right-click logins.txt → Edit with Notepad
   - Scroll to the bottom
   - Add your entries
   - Save (Ctrl+S)

3. FORMAT YOUR ENTRIES
   ───────────────────
   For SUCCESSFUL login (username: ravii, your IP: 192.168.1.x):
   2026-05-11 11:00:00,192.168.1.x,ravii,1234
   2026-05-11 11:00:05,192.168.1.x,ravii,1234

   For FAILED login (brute-force simulation):
   2026-05-11 11:30:00,192.168.1.x,ravii,wrongpass
   2026-05-11 11:30:05,192.168.1.x,ravii,wrongpass

4. TEST IN GUI
   ──────────
   - Run: java SecurityLogAnalyzerGUI
   - Click "📂 Load Logs File"
   - Select logins.txt
   - Click "🔍 Analyze Logs"
   - See your IP analyzed!
